# OBS 手动配置

## 1. 启动 WebUI

```bash
uv run obs-stage
```

打开 `http://127.0.0.1:6162/admin`，选择一个场景并保存主题。

## 2. 添加背景图

1. 在 WebUI 右侧点击“下载背景图”。
2. 在 OBS 当前场景点击来源下方 `+`。
3. 选择“图像”，命名为 `Stage BG [场景名]`。
4. 选择刚下载的 PNG。
5. 将位置和尺寸设为 `X=0 Y=0 W=1600 H=900`，并置于最底层。

## 3. 添加内容源

把显示器采集、窗口采集和 SPlayer 放在背景图上方。内容源的位置按 WebUI 的“内容源位置参考”调整。

不需要把采集源的圆角做进 OBS 滤镜；Stage Frame 会用透明槽位和前景边框形成裁切效果。

## 4. 添加舞台前景

1. 再点击来源下方 `+`。
2. 选择“浏览器”，命名为 `Stage Frame [场景名]`。
3. URL 使用 WebUI 的“复制源地址”，例如：

```text
http://127.0.0.1:6162/stage/half-screen
```

4. 宽 `1600`，高 `900`。
5. 勾选“使用自定义帧率”，填 `30`。
6. 放在内容源上方、弹幕源下方。

## 5. 添加弹幕

继续使用 bili-live-danmaku 的弹幕浏览器源，放在舞台前景之上。三个场景中弹幕统一放左侧。

## 6. 检查顺序

从下到上必须是：

```text
Stage BG
显示器采集 / 窗口采集 / SPlayer
Stage Frame
弹幕
通知 / 字幕
```

如果内容没有出现在槽位里，先检查来源顺序和位置，不需要给前景浏览器源加色键。
