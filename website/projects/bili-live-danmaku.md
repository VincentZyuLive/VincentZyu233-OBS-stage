# 💬 Bili Live Danmaku

Bili Live Danmaku 是直播中的透明弹幕面板，负责把 B站直播事件渲染成 OBS Browser Source 画面。

## ✨ 核心能力

- 普通弹幕、表情、头像、礼物、入场、点赞、SC 和舰长
- 礼物与入场合并、历史弹幕恢复
- 可配置整块圆角面板、字体、字号和颜色
- 内置 LXGW WenKai Mono
- Cookie 助手与匿名连接提示
- 与 OBS Stage 分开运行，默认端口 `6161`
